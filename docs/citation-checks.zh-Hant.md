# 引用與依據變動帶來的更新

[English](citation-checks.md) · [繁體中文](citation-checks.zh-Hant.md) · [沉澱指南](steep.zh-Hant.md)

Wenlan 追蹤頁面的依據關係，也檢查生成草稿中的編號引用。兩者分工不同：依據關係用來找出哪些頁面受變動影響；引用檢查則比對帶引用的文字與該次草稿所取得的來源內容。

## 記錄什麼

頁面保留支持它的來源與記憶參照。每次出現的引用會記錄編號、來源類型與定位資訊、分數、`verified` 或 `unverified` 狀態，以及 `sentence`（句子）或 `paragraph`（段落）範圍。同一編號出現在兩個位置，可以有不同結果。

已追蹤的來源變動時，相關頁面會被標記為待更新、推進來源修訂序號，並清除舊的引用結果。刷新與引用標註寫入時會檢查版本與修訂序號，避免套用根據過時頁面或依據狀態算出的結果。這是頁面層級的修訂追蹤，不是為每項事實陳述分別維護證據版本紀錄。

## 引用檢查怎麼做

1. 統一編號格式，移除超出所提供來源清單範圍的編號。
2. 比對帶引用的句子與它所引用的來源合併文字。支持分數取兩個方向的內容詞彙重合度較高者；目前門檻為 **0.5**。
3. 句子未通過時，改以所在段落重試，並記錄這個較寬的範圍。引用多個來源時，共同狀態來自合併文字的結果；每筆引用另記個別來源的分數。
4. 頁面刷新使用的共用合成流程中，若沒有任何引用通過，或未通過的引用出現次數多於通過次數，就捨棄草稿，不以它替換已保存的頁面。

通過的刷新草稿仍須遵循[頁面歸屬與審核規則](steep.zh-Hant.md#哪些自動更新哪些等待審核)。這項檢查門檻不適用於每一次手動或主動請 Agent 執行的編輯。

## 不能證明什麼

- `verified` 代表文字通過這項重合度檢查，不代表來源屬實、推論合理，或多個來源彼此一致。
- 沒有引用編號的敘述不在檢查範圍內。段落層級的支持，也比單一句子的支持更寬鬆。
- 斷句依據是 `.、!、?` 後接空白，詞彙過濾使用英文停用詞。這不是理解各語言語意的驗證器，不能假設不同語言的檢查範圍與分數表現一致。
- 刷新合成流程目前每個來源最多提供 **800 個字元**。檢查使用這些片段，不是完整原始文件，也不會另外搜尋網路求證。
- 外部變更須先讀入 Wenlan。單看頁面最近更新的時間，不能證明依據也已是最新。

引用供你查閱原始依據，歷史供你檢查變動。自動檢查狀態是查閱時的輔助資訊，不是正確性的保證。
