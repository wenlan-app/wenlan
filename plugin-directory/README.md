# Wenlan for the Claude plugin directory

Generated by `node scripts/gen-directory-plugin.mjs` from the Claude skills
(through the Agent Skills set). Do not edit files here by hand; CI runs the
generator with `--check`.

This edition holds skills as plain text only. It has no hooks, no scripts and
no bundled MCP server, so it fits the directory's rules for an organization
that is not Verified. The full plugin lives in `plugin/`.

What is different from the full plugin:

- The Wenlan MCP server is added to Claude Code by the Wenlan app, or by
  `wenlan connect claude-code`. `/wenlan` checks the connection and says so
  when it is missing.
- No session-start context is added automatically. Run `/wenlan:brief` to
  catch up.
- Each skill works out the Space itself, in the same order as the full
  plugin's resolver script.
